# Frozen World Data

Byte-exact maintained startup, world and script publishing inputs. `SOURCES.json` records every
source hash/size, translated code hash and whole frozen snapshot fingerprint. Original table
hashes and cross-table identities remain strictly checked by the two build-time compilers.
Runtime consumes generated immutable C++ catalogues, not these files or research.

No-inheritance reset values are limited to that startup contract. All shared definitions are
distinct from current instances/live actors; unlocking a definition does not create an actor.
Gameplay, script pages, money, village points and popularity retain their original identities.
