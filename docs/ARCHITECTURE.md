# 项目目标与架构

## 目标与依据

以C++17 + raylib复刻《冒险迷宫村》一代，尽量保留玩法、数值、事件顺序、UI与操作流程。先稳定二维世界和交互，再替换为3D表现。

[research入口](../research/README.md)及其维护规则、prototype、素材是产品唯一规格来源，输入身份见 [EVIDENCE](../research/dungeon_village_1/EVIDENCE.md)。产品侧只读维护交付，不读取 `research/work`、不执行逆向，也不把夹具、研究原型保护或跨版本截图数值当作原版规则。

研究覆盖、产品接入和原版一致性分别验收。当前已有完整世界持续推进及多人/月报验证，玩家建设和完整菜单仍未接入默认世界；具体差异集中在 [原版对照](reference/REFERENCE_CHECKLIST.md)与 [研究需求](reference/RESEARCH_REQUESTS.md)。阶段历史保留在 [B1记录](stages/B1-playable-prototype.md)。

## 三层结构

依赖从表现层向下，规则层只使用标准C++，没有raylib、窗口或屏幕类型。

| 层 | 接口 / 实现 | 目标与职责 |
| --- | --- | --- |
| 领域规则 | `include/ark/simulation/rules/`、`src/simulation/rules/` | `ark_world_rules`：地图/路线、人物控制/AI、战斗/救援、设施/商店、任务、现金、脚本、日期/月报与共同调度的候选规则 |
| 世界运行时 | `include/ark/simulation/`、`src/simulation/` | `ark_world_runtime`：真实新局、完整定义目录、唯一Owner，以及路由/场景/到访/日历/页面/任务/非人物消费者的投影和提交 |
| 桌面适配 | `src/desktop/` | raylib窗口、资源、输入、相机、投影、深度绘制及UI；`world_view`协调平台循环，`world_scene`读取世界视图 |

`src/app/world_simulation_main.cpp` 是标准C++无窗口入口，直接调用世界运行时；桌面入口 `src/desktop/main.cpp` 根据启动参数选择运行模式。启动参数属于 `ark_launch`，逻辑时钟适配属于 `ark_timing`，SEB/TSV解析属于 `ark_asset_metadata`。这些平台无关工具不持有第二套业务世界。

规则已按真实职责拆文件，运行时按跨域消费者拆文件。公开接口放 `include/ark/`，实现放 `src/`，实际模块README说明边界，不预建空ECS、服务容器或事件总线。

## 唯一Owner与事务

默认世界唯一可变聚合是 `StartupWorldRuntimeState`。它持有当前地图/实例、共同现金账本、随机流、实时人物/怪物名单、共享定义进度、任务、场景/日历、脚本页栈及表现缓存。

静态定义与可变共享进度、设施实例、人物实例分开。初始化对象仅用于真实新局投影，完成接管后销毁。路由、脚本、收尾和月报所需状态是在调用时构造的临时投影，提交后丢弃；不额外持久保存地图、资金或随机副本。

`prepare_startup_world_runtime` 在候选Owner内组合原资格和消费者，全部成功才替换当前世界。桌面每次获准更新还消费 `update_startup_world_render_cache`，保留原可见性及缓存时点；任一失败保留旧Owner并明确报告，不残留扣款、名册、随机游标或局部页栈提交。

实时名单、共同c/d前缀、FIFO控制、路线推进、设施使用/退出、非人物消费者、任务成功/收尾、事件续体和日期/月报沿维护运行时组合。不能把已存在的领域函数等同于玩家能通过菜单操作该功能。

地图格、连续x/height/z、原定义ID、维护实例ID、事件身份和现金统计均保留各自语义。到达收入与退出效果、金币/村子点数/人气、页面关闭与世界资格各自独立，UI不代替领域计算或补造事件顺序。

## 更新、页面与表现

默认不带参数、`--world` 和 `--check` 都选择完整世界；`--world` 是显式别名。窗口模式每个进程只启动一种世界，不运行旧Game来补建设，也不同步两个持久Owner。

逻辑更新与60FPS绘制分离。`ark_world_session` 的模拟线程独占世界提交，以47ms最小开始间隔、实际观测提交及卡顿不补算调度；倍速由源场景规则决定获准轮数。主线程读取不可变 `WorldFrame` 快照并以60FPS绘制，锁只保护命令队列和快照指针。输入按序在完整事务之间提交，相邻镜头请求可以合并，暂停/确认/倍速是不可跨越的顺序边界；有限命令批次后检查更新截止，持续拖动不会饿死世界。线程退出会唤醒并等待当前事务完成，失败发布明确错误并停止更新。原47ms门槛属于Android render/input路径，产品独立调度、桌面时钟和原框架生命周期尚未动态认证等价。

只对相邻快照中普通可见行走做位置插值，瞬移、进出设施及状态变化直接切换；逻辑位置、动作计数、伤害、金币和随机流不插值。命令提交后的快照不重复播放上一段位移。

页面栈与生命周期由运行时持有。玩家确认调用实际页面消费者，自动摄像页raw56自行推进；模态、暂停、场景状态和脚本是否跳过一轮沿原资格消费。无窗口入口的 `--auto-confirm` 和 `world-active/world-month/world-rank` 的自动确认只属于明确的测试输入。

月报采用用户确认的桌面政策：等待确认时停止世界更新，日期、人物、设施和随机一起冻结；按钮按真实报告消费者从第1页到第2页再关闭，最终确认仅领取一次村子点数。此前扣除的维护费不重复执行，也不伪造70次世界轮次。显式玩家暂停独立保留；无窗口入口仍运行源自动月报，作为规则基线。

已接入raw49晋级条件页消费者：从当前Owner读取四项真实条件，确认后按原页面生命周期返回。查看条件不执行晋级扣费、授称号或重复奖励，不能当作完整城镇晋级操作已接通。

源可见性会影响世界分支和随机消费，所以桌面从第一轮起把实际逻辑视口和zoom写入Owner，不能先在240×320参考视口运行，再改成宽屏。相机拖动/缩放只修改表现坐标，不选择人物目标或替代人物移动。

`world_scene` 根据当前地表分片、道路补块、栅栏/外部入口与实时名册建立稳定深度队列。人物/怪物图片按职业/性别/体型绑定，动作帧读原action counter和动画资格；血条、累计伤害、X2/X3现金、cd24经验和cd14升级标签读取真实状态。旅馆休息叠层按占用名单前4项与flags32显示，B<170计时，后段显示容量与displayed HP；隐藏人物身体不会隐藏设施面板。纯显示计划位于 `ark_world_visuals`，raylib执行器只绘制、不结算奖励。渲染FPS不会推进人物动作时钟。

命中与绘制共用逻辑布局，framebuffer使用原生像素（含Retina），素材最近邻采样，文字按物理密度生成。鼠标保持窗口点坐标，不重复乘DPI。表现层不直接扣款、改变占地、任务参与者或人物控制状态。

## 数据与来源

运行资源副本位于 `assets/`，世界定义与脚本位于 `assets/simulation/`。产品构建从这些副本生成数据，不链接research target，不在运行时读取APK或研究工具。

`assets/simulation/SOURCES.json` 记录冻结研究源与产品迁入结果，素材来源另见 `assets/SOURCES.json`。接入只消费已提交、已交付的维护代码；在途研究改动独立登记，不能悄悄混入产品。研究提交同步、产品构建/测试、真实窗口和原版动态对照分别保留证据。

## 旧切片边界

`ark_game` 及 `src/world/`、`src/facilities/`、`src/people/`、`src/economy/` 的旧建设/首访生活切片保留为诊断，显式入口是 `--legacy-slice`。`--ai-preview`、`--check-ai`、`--verify-play` 和旧 `--inspect-page` 名称自动选择该切片。`--tick-rate` 可配 `--legacy-slice` 或允许覆盖时钟的命名旧诊断；默认世界拒绝覆盖，`--verify-play` 仍要求原节拍。

旧切片七种单格建设、单人局部交接、1456步月前保护及初局固定布局诊断的契约见B1，不适用于默认持续世界。新增玩家建设应直接向完整Owner提交，而不是持续扩展旧模型或复制它的耐久状态。

## 剩余边界与3D

下一批重点是玩家建设桥：同一Owner内完成当前定义/资格、完整占地、扣款、施工、取消及已证移动/拆除，再连接原版目录/预览。任务选择/征集/出发操作、完整投射物/一般特效、经营与信息菜单、建筑正门演出仍按研究补接。

当前没有文件存取；内存检查点不是存档格式。不做旧档迁移，保存/加载需要独立设计。多人/月报自动测试、截图和引擎输入不替代OS鼠标、原APK速度/框架或持续动态对照。

产品冻结基线仍为seed1三个月，每套14530项检查、自然任务为0。研究提交40972a9已交付12/24个月及自然任务连续结果，但尚未迁入本批产品；不能由研究结果推导产品年度或自然任务链已经验收。

未来3D只替换场景、投影、渲染和拾取，复用同一世界身份、规则与命令。格坐标、占地和业务状态不嵌入2D等距参数；核心不提前引入3D引擎、材质、相机或ECS类型。
