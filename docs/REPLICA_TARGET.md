# 产品目标

以research中《冒险迷宫村》一代逆向结果为规则依据，使用C++17 + raylib复现原版可观察玩法、数值、事件次序、UI设计和操作流程。
二维复刻稳定后再推进3D化；3D改变投影、场景和输入适配，复用独立领域规则及行为验收。

用户已明确推倒旧工程、重新维护代码与文档。旧资金/居民/工程日/地图/道路/工具栏、旧schema和测试全部不是兼容要求。
当前产品仅为启动底座，不继承或声称任何旧阶段成果。

## 依据

- [research入口](../research/README.md)维护规则、独立示例和素材，示例中的夹具/安全策略不能自动视为原作事实。
- 固定APK是一代汉化重签包；输入身份以 [EVIDENCE](../research/dungeon_village_1/EVIDENCE.md)为准。
- 用户截图现有三批22张，第3批明确不同于APK版本。布局/文字可参考，价格/阈值/库存不能覆盖固定规则表。
- 原始地图/新局、完整人物优先级、部分退出/调度/战斗仍有缺口；不能以自定数值或demo补齐。

规则覆盖、产品接入和原版对照分别记录。编译/测试、画面、输入、原版一致性各自有证据，不能用一项替代其他项。
完整复刻指行为等价，不要求照搬Java类结构，更不复制反编译实现。
