# 逆向研究入口

本目录是《冒险迷宫村》一代规则、素材和行为证据的唯一研究入口，与产品工程分开维护。
[一代研究总览](dungeon_village_1/README.md)提供功能索引、包说明、运行入口和剩余缺口。

## 当前交付与下一步

已有独立 C++17 规则、素材提取工具和 raylib 可玩研究原型；原型中的地图、人物初值与时钟仍是夹具（fixture，测试用假数据），
不能作为原版新局。原版 UI 已归档三批共22张实况截图，并建立 [APK 渲染映射](dungeon_village_1/ui/PAGES.md)；
截图版本与固定 APK 不同，视觉和数值分别登记。

用户已确认先支持研究原型交互测试，再支撑产品首个原版风格建设切片。
本轮先整理文档与代码说明；后续研究优先恢复真实地图、新局初值和建设提交/返回流程。
产品编码由另一智能体管理，本目录不代写产品阶段状态。

## 消费约定

- 以 [输入身份与证据等级](dungeon_village_1/EVIDENCE.md)约束结论；证据支持的规格优先，不能把示例安全策略当成原作事实。
- 原始 APK、生成 Java 和缓存只作只读证据；维护交付是 [规则](dungeon_village_1/rules/README.md)、独立代码、原始数据及有来源清单的素材。
- 产品导入运行所需素材副本时登记源路径、哈希、尺寸、转换与用途；产品运行不依赖 APK 或研究缓存。
- 研究测试、原型窗口/输入、原版对照和产品验收分别记录；最新研究检查见 [验证入口](dungeon_village_1/VERIFICATION.md)。
- 本地 Git 检查点只包含已核对的研究改动；不夹带其他智能体的产品变更，不自动推送。
