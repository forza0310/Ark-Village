不使用后来截图中的视觉版本替换这些数值/指令，不改原表，也不把实例夹具冒充真实新局。
源归档和每个原始条目的SHA-256、字节数见[来源清单](SOURCE.tsv)。

## 唯一所有者与时序

接口见[world_scripts.hpp](../../example/include/dungeon_village_reference/world_scripts.hpp)，
回归见[world_scripts_test.cpp](../../example/tests/world_scripts_test.cpp)。标准C++17核心不访问文件、APK、
窗口、声音或随机生成器；读原表的工作放在适配/测试层。

原型将共同所有者的调用记录、续体、完成量、人气、页栈和相关目录投影到私有候选，
成功后统一写回。任何后段未知指令、缺目录、缺本地化或溢出均拒绝整段，不能先提交前段再继续。
本模块不保存另一份长期设施/人物世界。金融、职业、人物与设施定义同样由外层唯一所有者提供。

主场景原顺序为自动脚本扫描，然后续体扫描，之后才是世界AI，但不是每轮都执行三段。
低层`MainScene.java:L10b→L159`显示首个自动脚本触发后直接跳过本轮余段。
`L247→L159`显示续体扫描先减计数；首个`<=0`项删除、恢复保存的`P[9]`并执行后，立即跳过余段。
其后的旧项及恢复中新追加项本轮不再递减。新局7的`6,3`在触发轮保持3，后续合格轮才变2；
若入口保存了倍速第二轮，该第二轮仍可按实时aM继续扫描并减到2。不能把渲染帧与逻辑轮混用。
维护接口默认`first_only=true`对应原主场景；显式`false`只保留批量夹具用途，不认证原调用顺序。
是否允许这一主场景更新由外层页栈/菜单/事件窗调度判断，计数不是秒或渲染帧。

自动条件空矩阵为真，`0,0`为假。固定表仅7、35、200、204、225/226/227可以自动触发；
其他事件须由实际调用方发出。年/月/月内子周期比较先取原`P[1/2/3]+1`，随后用包容上下界判断。
条件类型5使用月内子周期`P[3]`，不是村级`UserData.k`；不能把新闻的时间门槛误写成村子星级门槛。

页栈插入遵守框架实际执行页`j`：有有效执行页时每页插到同一锚后，故存储顺序可能反于请求顺序。
201在场景执行上下文中得到“场景、新闻、发行公告”，不是按向量尾部追加；无执行上下文才取实时栈顶。
关闭只标生命周期4并恢复首个挂起下层页到1；真正删除是框架后段。关闭不驱动人气或续体结算。

90的页56读取实时第一怪物的缓存`u`，不是人物当前`n`或地图格中心。
[镜头消费者](../../example/src/world_scripts.cpp)将距离10..150映射步长5..26，同时推进两份摄像位置，
只有严格`distance<step`才直接对齐并关闭；没有怪物时直接关闭而不补演示目标。
