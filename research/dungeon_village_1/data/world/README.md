# 完整世界目录原表

本包为固定《冒险迷宫村》一代 APK 的世界规则输入，供研究原型构建时使用。
运行程序不读取 APK、反编译工作区或这些文本文件：构建脚本先验证全部固定 SHA-256，
再机械生成不可变 C++ 目录。来源、实现策略和截图版本不得混为同一份事实。

## 内容

|---|---:|---:|---|
| [monster.txt](monster.txt) | 36 | 17 | 全怪物成长、金币、击杀点数、体型、介绍程序 |

[asEventData.txt.SOURCE.tsv](asEventData.txt.SOURCE.tsv)。来源归档固定为 `xls.dat`，

原字节保持不变，拒绝用改表或补演示值解决测试问题。

## 构建入口

[完整目录编译器](../../prototype/scripts/compile_startup_world.mjs) 同时消费
[新局发布输入](../startup/)、[完整设施表](../original/tenantData.txt)及
[固定脚本原表](../scripts/original/)，输出全人物、职业、武器、防具、饰品、怪物、
任务、物品、设施、活动、配方与五份脚本原文。物品第12–15列四元素独立供壶投入，不借设施改良三列。
配方固定40×10并检查五类奖励引用，存取数据身份同步计入该表。哈希验证之后还复用新局编译器验证地图重编码
及新局字段，不信任未经交叉验证的 JSON 摘要。

[原表发布器](../../prototype/scripts/export_world_tables.cpp) 复用研究工具包的严格归档、
CRC 与解码接口；已存在的不同字节文件拒绝覆盖。目录规模与当前输入固定，不是通用
存档格式，也不包含旧档迁移。

## 调用字段边界

任务第10列`a.m.j`是遭遇普通怪物定义有序列表，第12列`z`是基础遭遇配额，
第14列`m`是待结算完成量。工厂及真实遭遇任务提供器保留这些值；首期探索的m为20。
该完成量先累加f215e，再由事件脚本22进入延迟人气，不当作金币、村子点数或建设费用。
任务第7列引用的首期探索设施为kind1，对应地图状态8；地图状态由真实设施setter决定，
不按旧夹具假定全部探索设施都是状态1。

怪物介绍程序在每个spawn之前按原请求位置同步解释，介绍程序注册维护身份2500+原ID；
不是把这个身份称为原aL事件ID。原表和[SOURCE.tsv](SOURCE.tsv)的字节/哈希不因字段解释更新。
装备/物品名称从原表发布，真实补货提示与目录奖励提示不借截图版本或英文占位名称。
