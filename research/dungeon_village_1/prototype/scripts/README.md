# 新局数据编译

[compile_startup.mjs](compile_startup.mjs)只在构建期使用 Node 内置 JSON 解析与 SHA-256，
从[发布包](../../data/startup/README.md)生成构建目录中的 C++ 常量，不手工维护第二套576格数据。
校验地图尺寸、未解释尾部、显示绑定、八个种子、单格目录、首访与职业派生契约；错误阻止构建。
定义投影同时保留种类、活动类别、定义方向、flags、形状、默认定义魅力；使用原表第9列显示绑定，
不从显示表第一条同定义记录猜最终显示。加载后地图由标准C++独立派生，不由脚本填预期格值。
使用组合另保留原表细分类、第25列等待、四属性/升级端点，以及首名人物职业第13/14列满足度门槛；
这些是只读规则输入，不代表已经运行默认AI或完成实例邻接重算，建设有效报价与原始经营端点分开。
退出属性保留原表第28/29列的原顺序，严格验证等长与六属性下标；不把属性0猜为经验值。
首名装配时武器重选计数6来自[较小源码消费者](../../rules/FACILITY_USE.md#weapon-choice)，
不是原表库存或生成器默认演示值；仅这一已证赋值由生成器投影，其余装备/使用状态不补造。
编译输入回归另交叉校验自动脚本集合/四月资格、事件89程序、初期武器解锁/rank/价格与道路显示深度flags。
运行时仅标准 C++17，不需要 Node、APK 或反编译目录。生成文件不能手改。
