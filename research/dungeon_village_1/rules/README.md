# 规则规格

本包文档按功能维护固定 APK 的行为证据与独立 C++ 契约。输入和证据等级见 [证据索引](../EVIDENCE.md)；
文件内的生成源码坐标保持原始行号，不代表维护代码位置。

- [状态与建设](STATE_CONSTRUCTION.md)：R1 六主题概览，包含实例持久化与全局聚合；R1 安全策略不是原作规范。
- [设施定义与邻接](FACILITIES.md)：85条定义、字段、几何、经营和来源去重。
- [地图访问](MAP_ACCESS.md)：绑定、准入、距离场、活动格和到达身份；不是原始地图文件解析。
- [人物与寻路](CHARACTERS.md)：自主调度、两级选择调用链、加权路径，以及旧/当前原型差异。
- [活动选择](ACTIVITY.md)：类别、候选、排序计权、快照选择一条链；完整人物优先级未恢复。
- [设施使用](FACILITY_USE.md)：到达、退出、升级提示与生命值小协议；不合并成一个完成回调。
- [事件与道具](FACILITY_EFFECTS.md)：定义共享改良、实例触发计数和延迟展示；不是完整事件解释器。
- [周期账本](ACCOUNTING.md)：金币/点数分离、费用与月报局部时序；完整日历候选暂缓。

## 维护方式

小结论追加到对应功能章节，保留证据等级和未知项，不再另起一个报告或阶段。
只有功能集合大到难以检索，或出现独立的输入/验收边界时才拆子目录，入口仍只维护一份索引。
文档引用维护接口和测试；代码包说明见 [example](../example/README.md)。
