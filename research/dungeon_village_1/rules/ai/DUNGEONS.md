## 进入与共享字段

`opcode21`先移除自身，再读取当前O格的实例并调用实例a；不是q的旧s/身份查询。
类别5将V/W/X/Z/aa清0，Y=`3+sum((职业等级−1)/2)`，各职业分别整数截断；**不清bw**。
随后o追加引用，不去重，也不加“实例状态非零”守卫。

首名进入且o空、g0时，两次扫描都不检查最后一条挑战记录：
前缀至少5条且全部类型0时抽2发168/169；全部类型1时抽2发170/171。
最后一条相反类型不妨碍提示。少于6条、已有成员或g非0不抽该票号；提示含人物定义身份与j1。
维护返回提示请求，未模拟该页面脚本。

阶段1长度为当前`Q*120 .. Q*240`，难度1..9整数映射；默认Q80得9600..19200。
Q是原日历计数常量，不是帧率/秒数。阶段1重置g，阶段2只重置设施更新计数。

| 维护字段 | 原字段 | 所有者与含义 |
| --- | --- | --- |
| progress/previous/percent | V/W/X | 人物对象；进度可负，W保存挑战回退点 |
| endurance | Y | 人物对象；不是HP，挑战可继续扣成负 |
| retreat_state/retreat_updates | Z/aa | 人物对象；每个引用推进，不按唯一ID去重 |
| constrained | bw | 上轮相邻封顶结果，供下一轮领队步长 |
| progress/extent/percent/previous_percent | g/h/i/j | 设施实例；g保留挑战回退前最大值 |
| challenges | k | 设施实例；有序六整数记录，不是全局任务目录 |

六字段为`阈值/类型/状态/年龄/第五字段/第六字段`。
类型0的末两项是奖励类别0..3/定义ID；类型1是怪物定义ID/挑战强度，**第五字段不能统一限制0..3**。

## 一次队伍更新

本模块接收设施c前缀已加过的计数，不重复推进设施通知d或人物d计数。
没有成员时立即返回，连显示i/j也不刷新。

1. 从o索引1开始读取连续旧bw，领队步长10每人再加3，然后清全部成员bw。
2. 逆序读取实时o，每个引用aa加1。Z0先W=V，普通成员+20；首人V≥旧g加步长，否则加双倍。
   X使用静态`Tenant.a(V)`：没有全局任务/任务设施得0，否则按**全局任务设施h**缩放，不是当前设施h。
3. Z1且新aa≥20调用实际撤退。成功q删除首个匹配引用；删除早于本索引时，后续可能重复处理同一人物。
   没合法落地点也算发生撤退调用，触发重排。
4. 有撤退调用才按严格大于、内层逆序两两交换；不是稳定排序。相邻跟随者V取`min(V,前人V−300)`，
   可为负；更新X并在实际改变V时置bw。不能改成max或钳0。
5. g取本轮普通推进的最大值与旧g中的较大者；计算挑战所用比例。最大值在相邻封顶、挑战回退之前取得。
6. 逆序处理挑战；年龄先加1，旧状态决定本次分支。完成条件g≥自身h最后检查。

### 挑战时点

| 旧状态/类型 | 本次行为 |
| --- | --- |
| 0/0，队伍比例达阈值 | 直接授予目录奖励，状态2/年龄0；本轮不立即进入2的阻挡分支 |
| 0/1，队伍比例达阈值 | 逆序处理X达阈值且Z0的成员；计数整除25才各扣Y与强度，并发标签231 |
| 1/0，新年龄≥10 | 按设施格抛出奖励，删除记录；没有合法目的地仍删除，不授予库存 |
| 1/1，新年龄≥40 | 删除记录 |
| 2/0 | 达阈值且Z0的成员V回W；新年龄≥40转3/年龄0，该转移轮仍阻挡 |
| 3或其余无消费者状态 | 仅年龄推进，没有擅自奖励/删除 |

战斗先检查扣后强度≤0：转1/年龄0，但**不跳出成员扫描**，后续仍可扣Y和强度成负。
未击败时，Y>0或本轮未扣减就V回W；否则Z1/aa0等待撤退。X不随V回退立即重算。
231只是进度显示，绝非经验或伤害。其参数来自X的0..100→−8..153整数映射后加16。

g≥h先阶段2/设施计数0，再按当前o顺序对每个引用清位1、c0、排等待`索引*5`和活动0。
重复人物可被后一个引用再次覆盖队列。此时仍不清o，不把活动0同步执行掉。

## 实际撤退与落地

人物a(设施格)先传送n水平位置到格中心，更新s；保留旧高度/t/u/ax。
按原八方向顺序找地图内、城外严格边界谓词、逻辑状态4的目的地，不按路径成本或设施可达性。
没有候选时立即返回，**传送已经发生**，HP/状态/占用和随机都没有其他变化。

有候选才依次抽候选数、80、80；两偏移为10..89。水平速度差/36，竖速80/17；
清97→按新s执行q并删除首引用→清控制/c20→直接HP0→动作7。
q仍需精确O格/定义/实例身份匹配，不能仅比较“同一设施”或给施工0额外守卫。
HP直接赋值保留动画标记和旧计数；不通过伤害/死亡消费者添加击杀统计。

状态20的c先水平移动，然后检查**旧B≥36**；因此分母36不代表只移动36次。
达到阈值后高度归0/清三轴速度→旧u显示18→c0→**直接o0**→c2。
维护的落地回调只在私有候选上执行原活动消费者，最后总要c2，哪怕o0没有路线；
缺消费者或准备错误整段回滚。不能替换为队列`[8,0]`、猜一个下一目标，或在回调外提交半状态。
旧u由表现适配显式传入，不用0坐标补造；c2清o0新排的控制，但保留其路线等已提交字段。

## 阶段2与任务收尾

阶段2接收前缀后的计数，新计数至少10（`at`最后项），才检查全局活动任务：

- 无全局任务：以z[0].n恢复未成功探索格，再逆序删除bq中种类0且无设施引用/同位置的任务。
- 任务种类1：只调用全局任务清理，立即返回，没有经验/摘要/成功恢复。
  全局清理c.k.d先清**所有人物定义**flags2，再移除活动任务/清h，不只清当前参战实例。
- 任务种类0：金额为任务难度×5。按全局参与名单原序，逐定义找bl首个同定义人物；有实例才显示奖励、
  对定义提交延迟20的经验、清该人物2048。重复参与者重复调用，缺实例不补人物/奖励。
- 排页面30与32；32两次独立抽参与名单，允许相同，也允许抽到当前无实例的参与者。
  摘要奖励取**全局任务设施**剩余全部类型0记录，不按状态过滤，不重新授予目录。
- 顺序：事件126→将任务m.m加到待结算f215e→恢复成功格→任务成功统计c.k.a→清全局任务→未见201→未见92。
  c.k.a不是“解锁任务”：增加全局成功数v、部分探索数w和定义完成次数t，按flags调用特殊成长/怪物开放，
  并在没有flags2活动任务时增加G及其阈值提示；`c/k.java:62–104`。这些交给任务所有者，不错误命名为解锁。

[完成候选](../../example/include/dungeon_village_reference/dungeon_ai.hpp)返回这些有序请求和摘要数据，
不冒充已有全局任务/UI/地图改写所有者。人物奖励显示与定义延迟成长是两次调用，不把标签直接加到经验L。
