# R2-M 类别 -1 的区域格回退

## 状态与授权

状态：Completed；更新：2026-10-03。沿用用户持续自主研究授权，仅维护 research。
前置为 [活动类别计划](R2-activity-choice.md)与 [候选快照](R2-activity-candidates.md)。

## 方案与边界

A（采用）：复用完整快照校验，按外部抽签前缀推进最多六次的区域格选择，输出目标/已消费票号数/
需要的下一抽范围。B：从所有满足区域条件的格里一次抽取会取消第六次回退，不采用。
C：自动抽到合格格为止会变成无限重试，也改变概率和 RNG 消费，不采用。

1. 输入完整候选快照、城镇下界和至多六个票号。下界来源固定为原城镇数组的 `[0][1]`，
   不把它误作上界。`bottom + 2` 用 int64 比较，不复刻 Java 输入越界回绕。
2. 空候选成功返回 no_candidate，消费零票号，不要求 RNG。非空输入缺下一个票号返回 needs_draw，
   保留已消费数量与下一次上界；它是正常前缀结果，不是非法输入或路径成功。
3. 前五次每次按完整候选长度抽下标，可重复；命中 `y >= bottom + 2` 就停止。
   五次均失败，第六次按同一范围无条件返回其格，不沿用第五次、不取最近格。
4. 不按定义魅力、类别、实例阶段或可达性再次筛选；来源/重复/可空实例和成本保留。
   本函数不生成活动 6/8 的上游候选、不求路径、不预约或收费。
5. 仅读取实际需要的票号；提前选中后的尾部不解释，也不消耗。已读取票号不在 `[0,size)` 内拒绝，
   不返回部分计划。超过六项拒绝是 Ark 资源契约，非原随机接口的行为。
6. 同前缀可重放/延长；函数自身不拥有 RNG 状态，调用者按 needs_draw 指定范围取下一票号。
   票号不是原作均匀随机序列复刻，固定次数/局部规则与外部抽样实现分开。

## 验收

- 五个提前命中位置、精确边线、第五次失败后 needs_draw 与第六次无条件回退。
- 票号可重复、不使用魅力/阶段/实例/距离、空候选、未消费尾部与合法前缀重放。
- 非法已消费票号/超长/伪造快照/下界整数极值，错误无目标或部分计划。
- 1,000 组固定种子显式六抽差分，完整候选生成/类别 -1 计划/区域选择/路径组合。
- 三套示例、两套原型回归、格式/诊断/中文链接及本地检查点。
