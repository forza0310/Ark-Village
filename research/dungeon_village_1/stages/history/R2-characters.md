## R2-B 人物自主行动与路径规则

<a id="autonomy-状态与授权"></a>

### 状态与授权

- 阶段：R2-B；状态：InProgress（研究/自动验收完成；鼠标免验，用户试玩未运行）；更新：2026-10-03。
- 核心和新版画面已通过；用户已免除鼠标验证，用户试玩未运行，见 [试玩清单](../PLAYTEST.md)。
- 范围只在 research；不实施产品 M3，不修改顶层工程。
- 用户指出人物应自主移动，并要求继续逆向及 Git 管理；随后明确要求持续自主迭代、无需询问、
  进入 2–3 小时无人值守模式。本记录据此授权自主选择后续研究设计，不冒充此前 R2-A 已确认此范围。
- 证据与未知项见 [自主行动报告](../../rules/CHARACTERS.md)。

<a id="autonomy-目标"></a>

### 目标

建立可执行、可测试的人物自主生活原型：玩家建设和移动设施，人物自动选择可达设施，行走、使用、
完成或取消并再次决策。保留原作已证实的四向、道路/空地离开成本；没有恢复的策略和值用显式夹具。

<a id="autonomy-候选与自主决定"></a>

### 候选与自主决定

| 方案 | 内容 | 取舍 |
| --- | --- | --- |
| A（采用） | 证据驱动的加权路径模块，加独立且标明夹具的自主策略 | 可以验证完整状态闭环，不冒充完整原作 AI |
| B | 先恢复全部类别/数值/优先级，再做逐行为对应 | 保真目标强，但巨型方法存在控制流警告，无法立即保证可执行 |
| C | 只定时随机游走 | 实现小，但不能研究设施选择/使用，也不能回答道路成本问题 |

采用 A；B 的数据与语义恢复作为后续独立研究继续推进，不用 C 替代设施行为。

<a id="autonomy-设计"></a>

### 设计

1. 标准 C++17 路径模块与 raylib 无关。输入有界网格、道路/空地/阻塞/设施终点类别，输出
   四邻接路径和累计成本；无效输入、不可达和超限有明确结果。算法使用标准库最小堆。
2. 路径按离开格计费，道路水平 5/垂直 7、空地水平 50/垂直 70。设施终点可进入但不能当作
   普通穿行格；演示场景的入口仍为单点夹具，暂不复制未知 `Tenant.z` 几何。
3. 自主模拟唯一维护人物位置、路径游标、活动与重试时钟。选择可用且可达的实例，再调用 R1
   预约契约；有多个实例时采用确定性的轮换策略。这是测试策略，不声称原作轮换。
4. 正常原型移除 `Visit` 操作；每帧只推进模拟，绘制只读其状态。`--demo` 保留自动验收场景，
   可直接请求活动用于覆盖边界，但不成为玩家命令。
5. 移动/撤除/无效目标使本次活动取消，释放预约和路径；重选不能继续旧路径或发放旧活动效果。
   无候选有有界重试，避免每帧全图寻路。使用完成只调用 R1 一次效果契约。
6. 分离地图格整数位置与客户端连续插值。速度、等候、使用时长和设施定义仍为夹具。
   本阶段不新增存档、不包含战斗/全职业/任务 AI，不声称完整原作等价。

<a id="autonomy-验收"></a>

### 验收

- 路径覆盖起终点相同、四邻接、障碍、不可达、边界、成本方向差异、道路绕行更便宜、离开格计费、
  设施终点不可穿行、成本/尺寸溢出与搜索预算。
- 自主流程无需鼠标指挥：空闲、选择、预约、路径、到达 `in_use`、完成效果、释放、再次决策。
- 两名人物不争用同一预约；无候选不修改资金/效果，移动/撤除后清理，迟到/重复完成不生效。
- 小步/大步时间推进、暂停/非法 delta、稳定 ID 与多实例行为有确定性检查。
- 独立示例与原型 Debug/Release 构建和 CTest；有界真实窗口演示、非空截图、正常退出。
- 原作成本、夹具策略和未知几何在文档与接口中清楚分开；中文文档和本地链接通过。
- 只提交维护 research 文件，不提交 APK、生成 Java、工作缓存，不夹带产品改动、不推送。

## R2-H 人物活动类别计划与权重票号

<a id="categories-状态与授权"></a>

### 状态与授权

状态：Completed（独立类别计划/票号切片）；日期：2026-10-02。延续用户持续自主逆向授权，独立研究，不改产品或旧模拟。
证据见 [类别选择报告](../../rules/ACTIVITY.md#categories)。仅恢复小型类别选择函数，不宣称完整人物 AI。

<a id="categories-方案与边界"></a>

### 方案与边界

A（采用）：纯函数返回类别计划，随机源留给调用方；另提供受检查的权重票号索引选择。
B：复制巨型目标选择状态机，疑似重复/缺失控制流太多；C：给计数猜饥饿/疲劳或用轮换冒充原作，均不采用。

1. 输入活动操作参数、11 类可用候选计数、6 项人物访问计数和原标志位。计数使用非负宽整数。
   类别存在用 count > 0，不将候选数量乘进类别权重。参数 0/2 同规则，6 为另一计划，其他 unsupported。
2. 固定权重表来自小型 helper；0/2 按标志 8192 与访问计数筛选类别 1/2/4，必要时加入类别 3。
   回退权重按此前列表长度（含零权重类别）索引，不按总权重或候选总数。
3. 未设 8192 且访问槽 0+2 至少 5 时，仅存在类别 4 选项才强制类别 3，否则没有目标；
   不把源码的目标类别 3 擅自改成 4。加法用无符号宽中间值避免 signed overflow。
4. 活动 6 依可用数加入类别 8/6，再始终加类别 -1 权重 60。固定设施原表无 6/7/8 类，
   非空这些类别的测试明确为合成输入，不宣称原始数据实际产生了这条设施路径。
5. 权重抽取接收外部整数 ticket，要求 0 <= ticket < 权重和；零权重项永不命中。
   负值/溢出/无权重/越界票号明确拒绝，无部分索引；不内置 RNG、不复刻原作带偏差取模。
6. 不生成候选地图、不解决多格重复候选、不执行类别 3 的住宅/出口或 -1 的地域回退。
   不把独立计划替换成旧可视轮换策略；原作实例权重来自定义魅力而非邻接后实例值。

<a id="categories-验收"></a>

### 验收

- 0/2 等价、0–5 访问计数各门槛、标志开关、候选数量不改变权重、零权重项保留/不命中。
- 强制类别 3 与无类别 4 情况、回退权重索引、活动 6 两候选/空候选、负数/未知操作/最大计数。
- 每个票号对应精确区间、空/零/负/溢出/越界拒绝；固定种子权重数组与独立展开票号序列差分。
- 独立逻辑参考穷举类别计划，示例三套、原型两套/工具回归、格式/链接/本地提交。

<a id="categories-当前交付"></a>

### 当前交付

完整合法票号区间和 200 组随机权重展开差分；零权重项保留但永不命中。
首轮编译/测试通过；示例 Debug/Release、ASan/UBSan 各 11/11；原型两套各 12/12；工具两套各 5/5。

<a id="ranked-方案与接口"></a>

### 方案与接口

A（采用）：由上游传入已筛选/按成本排序的设施格，严格验证记录后按每格定义魅力抽实例，再取该实例
列表首格。B：按实例去重会改变已核实概率；C：恢复完整巨型人物方法会扩大未解释范围，均不采用。

1. 记录包含格坐标、实例/定义 ID、活动类别、实例原阶段、定义魅力与成本。保留输入排序，不重新排序。
   负值/无效身份/重复坐标/成本逆序/同实例或同定义字段冲突/超过一百万格拒绝，无目标结果。
2. 同实例多格合法，必须保留多次出现；共享定义的类别/魅力一致，实例阶段独立。只有阶段 1、
   所选普通类别的记录参与权重，0/其他阶段不加权。非选中类别仍检查完整结构。
3. 仅支持已有类别计划中的普通 1/2/6/8；类别 3/-1 为特例，4 为按格计数抽取，明确 unsupported。
   类别 6/8 无固定设施定义，对应测试仍为合成输入。
4. 总权重按每格定义魅力累计，复用已验证票号函数；零魅力不命中，溢出/非法票号无部分输出。
   输出抽中的出现下标和最终目标下标/身份：同实例最终目标为输入列表首次出现格，未必就是抽中格。
5. 不重新验证物理地图绑定或自动生成上游资格；调用方必须提供完整合规候选。平局次序由输入保存，
   不宣称是原作稳定排序。不把实例邻接后魅力传作定义魅力，也不擅自按距离乘权重。

<a id="candidates-问题方案与取舍"></a>

### 问题、方案与取舍

常规和低层输出已交叉核对较小 `RouteSearch` 候选函数。候选资格、类别计数和类别 4 的扫描对象
不是同一集合；事件还能追加重复/不可达格。继续把所有可达设施交给 R2-I，会丢失这些事实。

A（采用）：维护候选快照生成与类别 4 票号纯函数，保留出现项、阶段、可空实例/距离及来源；严格
校验完整输入并复现已核对的交换顺序。B：稳定排序/去重/统一过滤会改变平局或概率，不采用。
C：复制巨型角色方法超出当前证据与 clean-room 边界，不采用。

<a id="candidates-输入与所有权"></a>

### 输入与所有权

1. 接收已维护搜索生成的完整距离场、每格定义 ID、定义类别/魅力、实例定义/阶段、城镇边界和事件格。
   不读取 APK，不把地图类别当显示状态。矩形内判定严格排除边线，来自 `c/h.java:316-321`；边界值
   由调用者提供，不猜初始原地图。输入字段与映射/边界不合法、绑定不一致整批拒绝。
2. 活动参数 6/8 收有限距离、状态 4/9、在城镇上边界下方且不在严格内区的格；7 收有限距离内区格。
   其余参数使用同一普通候选分支，这只是底层生成函数，不代表上层支持全部活动。
3. 普通候选按行主序收有限距离、非起点、状态 1/8/6/7/10/9、有实例且阶段非零的格。仅当起点
   有实例时，排除实例 ID 等于上次访问 ID 的格；不能无条件排除上次实例或整个当前实例。
4. 普通分支随后按输入事件顺序追加类型 1 的事件格，不另做可达性、阶段或重复过滤。之后删除首次
   出现的起点格，而非删除所有同坐标出现项。不可达距离保持空值，不冒充零距离或可执行路径。
5. 收集完成按原外层递增、内层逆序且仅严格更小交换；平局可能被第三项交换间接反转。由于是平方
   比较，候选上限 4,096 项，超限返回资源拒绝且无部分快照；这是 Ark 安全契约，不是原作地图限制。
6. 类别统计仅计没有实例或阶段 1 的出现项；其他阶段仍保留定义项。普通加权列表仍只使用阶段 1。
   快照返回类别计数，可输入 R2-H；不自动合并人物完整角色资格/任务优先级。
7. 类别 4 票号范围取上述类别计数，但匹配扫描全部定义类别 4 的出现项，不另检查阶段。
   因此较早的阶段 2 项可能被选中，不按推测意图纠正。无计数、非法票号、伪造快照分别拒绝。

稳定 ID、整数边界、完整输入验证和不复刻异常后的部分向量都是独立安全契约。
R2-I 仍是唯一坐标/有实例/有限距离的普通设施接口，不能将本阶段任意事件快照直接传入或去重适配。

<a id="arrival-方案与范围"></a>

### 方案与范围

A（采用）：拆分较小到达记账函数中 `N == -1` 且细分类不是 1/4/5 的普通路径，输出纯候选。
B：将全部收益放在使用结束会与到达直接调用冲突，不采用。C：复制同行、道具、装备抽选及使用序列
扩大未解释范围，不采用。证据与未知见 [到达报告](../../rules/FACILITY_USE.md#arrival)。

1. 输入稳定人物/实例 ID、定义 ID、定义种类/类别/细分类、人物类型/标志/选择值、已派生实例价格，
   以及到达函数所需的状态投影。原表定义 ID 可为零，稳定人物/实例 ID 不可为零。
2. 状态投影只含六项访问计数、类别 1 的 K、类别 6 的 M、上次访问实例、角色 B[2]、当前月份设施
   v[month][0]。B[2] 是统计，不是钱包余额；没有复制全部 UserData 或改变存档结构。
3. 按核对后的分支优先级增加访问计数，类别 1 同时加 K，类别 6/细分类 2 的对应分支清 M。
   种类 1 会阻止部分计数分支，但不阻止更早的类别 1/2 分支。
4. 访问计数和上次访问不受收费守卫控制。只有未设 512/256、人物类型为 0 且价格大于零时，
   候选才给角色统计和设施月销售增加价格，并返回设施金币收入金额。负/零价格不发收入。
5. `N != -1` 或细分类 1/4/5 返回 unsupported，不能用调用者传来的任意价格绕过其选择副作用。
   所有输入先验证；负计数、无效身份/类别/月份拒绝；有符号统计保留，累加溢出无候选。
6. 结果不是幂等命令，也不是资金已入账。调用者先校验地图目标身份，并将候选状态与唯一现金事件
   一起提交；候选自身不预订设施、不增加共享定义使用次数、不应用退出效果。
7. int32 范围保护、稳定身份和整批拒绝属于 Ark 安全契约；不复刻 Java 回绕或部分副作用。

## R2-M 类别 -1 的区域格回退

<a id="regional-状态与授权"></a>

### 状态与授权

状态：Completed；更新：2026-10-03。沿用用户持续自主研究授权，仅维护 research。
前置为 [活动类别计划](R2-characters.md#categories)与 [候选快照](R2-characters.md#candidates)。

<a id="regional-方案与边界"></a>

### 方案与边界

A（采用）：复用完整快照校验，按外部抽签前缀推进最多六次的区域格选择，输出目标/已消费票号数/
需要的下一抽范围。B：从所有满足区域条件的格里一次抽取会取消第六次回退，不采用。
C：自动抽到合格格为止会变成无限重试，也改变概率和 RNG 消费，不采用。

1. 输入完整候选快照、城镇下界和至多六个票号。下界来源固定为原城镇数组的 `[0][1]`，
   不把它误作上界。`bottom + 2` 用 int64 比较，不复刻 Java 输入越界回绕。
2. 空候选成功返回 no_candidate，消费零票号，不要求 RNG。非空输入缺下一个票号返回 needs_draw，
   保留已消费数量与下一次上界；它是正常前缀结果，不是非法输入或路径成功。
3. 前五次每次按完整候选长度抽下标，可重复；命中 `y >= bottom + 2` 就停止。
   五次均失败，第六次按同一范围无条件返回其格，不沿用第五次、不取最近格。
4. 不按定义魅力、类别、实例阶段或可达性再次筛选；来源/重复/可空实例和成本保留。
   本函数不生成活动 6/8 的上游候选、不求路径、不预约或收费。
5. 仅读取实际需要的票号；提前选中后的尾部不解释，也不消耗。已读取票号不在 `[0,size)` 内拒绝，
   不返回部分计划。超过六项拒绝是 Ark 资源契约，非原随机接口的行为。
6. 同前缀可重放/延长；函数自身不拥有 RNG 状态，调用者按 needs_draw 指定范围取下一票号。
   票号不是原作均匀随机序列复刻，固定次数/局部规则与外部抽样实现分开。

<a id="regional-验收"></a>

### 验收

- 五个提前命中位置、精确边线、第五次失败后 needs_draw 与第六次无条件回退。
- 票号可重复、不使用魅力/阶段/实例/距离、空候选、未消费尾部与合法前缀重放。
- 非法已消费票号/超长/伪造快照/下界整数极值，错误无目标或部分计划。
