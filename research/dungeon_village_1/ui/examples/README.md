直接用浏览器打开[index.html](index.html)。不依赖网络、npm安装或后端；HTML、CSS、JavaScript均在本目录，素材和截图引用research已有文件。需要HTTP时在仓库根目录运行：

```powershell
node research/dungeon_village_1/ui/examples/preview.mjs
```

访问`http://127.0.0.1:8766/ui/examples/index.html`，退出预览后用Ctrl+C结束服务。[预览器](preview.mjs)只允许三个页面文件、五张原素材、五张来源截图的GET，禁止目录枚举及任意路径读取。直接打开HTML不需要启动服务。

| 示例 | 内容／来源 | 可供产品使用的范围 |

| 主／系统菜单 | Steam S042／S049 | 左主菜单、右侧子菜单、父级选中；图标用占位符、未绑定NEW条件，文字和层级可参照 |
| 信息小窗 | Steam S041 | 木色信息框／白正文／橙色“好的”；按钮只展示样式，不写档 |
| 人物四页 | APK raw60局部合同：概览、六属性、四装备、魔法 | 字段与路由示意；没有同身份Steam人物详情截图，布局／头像／EXE操作均待认证，所有数值留空 |

原Steam完整图在示例右栏，可打开检查，不裁成运行素材。原图含标题栏，DPI与客户区缩放未测；本例响应尺寸、CSS字体、手形位置、边框实现和键盘焦点属于研究适配，不宣称精确EXE像素与热区。

本例建筑图、木纹、标题带、手形、类别条复用固定APK原资源；不以复用证明EXE调用绑定。右下返回与窗口主体分开。建筑详情→道具列表→结果参考→列表→详情仅模拟页面层级；真正原流程还有76演出，使用后库存与字段由Owner返回，不能从该示例的固定截图数值更新产品。

人物切页使用箭头；礼物与转职只报告路由，不生成业务数据。原装备页方向输入先在四槽内移动再切页，本例暂未模拟该键盘细节。原raw60初始化重算及教程属于Owner逻辑，不放进绘制。详情不能用于直接控制冒险者移动。
