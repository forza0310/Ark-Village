- 原53结果绘制的类型4分支没有专用文字／效果；维护原型明确拒绝未接类型4，不把空分支解释为成功。
- 通用新增活动提示`c/n.v()`并没有同样排除27；如果外部状态令27满足p1/rtrue等条件，该提示查询可能与普通目录不同。它证明两个消费者谓词不同，**不证明原游戏存在能自然产生该状态的操作**。
