## X4现有事实与最小补充

固定来源`work/decompiled/sources/d/a.java:3456`的`b(o)`从X索引0向后读取；`3577`的kind4分支不加入深度排序，和同一X中的其它效果按原索引穿插。这里只认证X内部顺序；它相对整个场景／HUD的完整调用相位尚未在本次审计闭合，不能声称无条件置顶。

六字段为`{4,age,rawX,rawY,velocity,acceleration}`。当前真实普通死亡在`prototype/src/startup_world_runtime_nonactors.cpp`依次追加X20、X3、X4，X4初值`{4,-2,rawX,rawY,-320,29}`；既有`startup_world_runtime_nonactors_test.cpp`核原序及声音23。金额只在X3／账本，不是X4的负运动参数。

`d/a.java:3577–3590`读取age≥0才画：先经`c/a.a(int,int,int[])`镜头换算，再加整数运动
`(velocity*age + acceleration*age*(age+1)/2)/100`；age≥`23/2`（即11）后强制为-16，最后正位移截为0。整数除法向零截断；有限合法年龄和真实载荷不会溢出，维护坏载荷须显式拒绝，不能默默依赖C++溢出。帧为`(age%14)/2`，所以14以后循环，不是保持末帧。`d/a.java:4034`及现有`startup_world_runtime_scene.cpp`更新到23退休；查询不得再次推进／退休。

镜头换算来源`c/a.java:97–102`：x为`M+rawX-trunc(cameraX)`；y为`P+R-(N+rawY-trunc(cameraY))`，M/N来自原视区两端整数平均。rawX/rawY是死亡时保存的投影点，不能读取当前人物位置，也不能当世界格坐标再次等距投影。最小绘制接口可保留该原始锚点，返回相对其换算结果的运动偏移，由已核镜头适配恰一次转换。
