## 观察项目与顺序

每项最多8分钟或3次尝试，总窗口操作不超过30分钟；取得必要证据即可提前结束。A–C优先，D仅有现成条件才做。记录可见事实与不确定项，不靠多次刷新硬凑样本。

### A．标题布局、选择与背景运动

仅在标题可安全取得时：

1. 保留完整窗口原图，记录窗口外框／客户区尺寸；DPI或缩放未知就填未知，不改系统设置取数。
2. 分别记录“开始游戏”和“纪录”选中状态：文字、选中底色、指示图形、位置、按钮与世界背景的层次。记录顶部设置／键盘／语言及底部按钮的可见状态；不要点网站外链、改语言或设置。
3. 通过当前工具支持的方式采一小段背景人物与Logo变化：有限连续截图或可用录像，注明实际时间戳、采样方式和间隔。至少保留人物出现、走动、遮挡或离开中实际取得的状态。不能把墙钟间隔或截图数写成逻辑tick、内部20槽或随机抽数。
4. 鼠标移动、单击、第二次点击、键盘方向／确认分别观察实际效果。一次只测一种输入，每个动作后重新观察；不要预设“悬停即选中”“第一次只标记”或“双击才确认”适用于本页。得到明确结果就停止，不进行高速连点。

若从游戏内无法安全回到标题，A填未覆盖，不代用历史S038作为本次截图。

### B．纪录两页与返回路径

可从标题或游戏内菜单进入；报告实际入口，二者不能混为同一条操作链。

1. 捕获第一页完整画面：窗口标题、主题标签、数字与单位、村名所在区域、插画人物／背景、翻页箭头、返回按钮和后方世界是否淡化。
2. 用实际可用按钮或方向键翻到第二页，再返回第一页，记录是否循环、选择或动画是否重置，以及输入方法。
3. 观察返回：回到哪个父页面、父级选择是否保留、游戏内日期是否发生可见变化。截图不足以判断暂停时填未知。
4. 不把“最高资金”当作当前所持资金；不由页面名推断读取哪份文件。记录画面数字可以用于后续比较，截图中的真实村名不抄入报告正文。

无通关纪录、只有资金纪录或全部为空都是有效状态；不要为补“有纪录”界面新造分数。

### C．新局配置与取消保留

仅从标题的空栏入口或已明确安全的实验会话进入。若需要接受覆盖警告才能到配置页，停在警告并将配置页记为前提不足，不擅自接受。

1. 捕获配置页：四项名称与顺序、默认可见姓名／性别、人物插画、背景、输入框／按钮、指示图形、取消入口。未知内部页号不要只因像APK就认证为Steam raw91。
2. 只切换性别，观察尚未自定义姓名时姓名／人物插画是否改变。记录操作前后画面。
3. 在允许编辑的实验草稿中，输入非私人固定测试姓名 `UI测试甲`，切换性别，观察名称是否保持。村名如需验证可用 `UI测试村`；不要为证明上限粘贴巨长字符串。
4. 捕获文本输入方式：游戏内编辑框还是平台弹窗、是否有字符计数／限制提示、确认和取消如何返回。短字符串被接受不能证明原12／14参数的字节或字符算法；没有实际边界实验就写未测。
5. 取消配置、重新进入同一安全入口，观察此前草稿是否保留。保留输入前、取消前、重进后三个时点，不凭印象结论。
6. 全程不按最终“开始游戏”。不要声称取消使所有共享定义／自定义标志恢复；仅报告可见文本和图像。

如果当前草稿属于用户准备开始的真实游戏，只观察，不改其姓名／村名；编辑与取消实验另标未覆盖。原值如需记录仅留受限本地截图，不公开真实名字。

若当前状态允许，分别尝试一次早确认与等待提示后的确认，记录是否推进；不要将秒数换算为75／45等内部门槛。秘书／大臣的姿态、背景／内框遮挡、继续箭头位置及声音只记可观察内容，不按PNG列数猜SEB帧，也不凭听感推音频ID。
