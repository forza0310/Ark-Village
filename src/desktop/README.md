# desktop

Windows/raylib表现层读取不可变WorldFrame；业务输入与实际呈现事实通过WorldSession的FIFO交给唯一模拟Owner。核心不依赖窗口、纹理或屏幕坐标。来源与验收见[架构](../../docs/ARCHITECTURE.md)、[本批计划](../../docs/MILESTONES.md#research-9cee27a-build-record)及[B1记录](../../docs/stages/B1-playable-prototype.md)，历史验证不在本模块重复维护。

| 目录 | 职责 |
| --- | --- |
| application | 进程窗口、标题/两栏启动、世界绘制与输入协调 |
| input | 页面手势、已画几何/marker、pending与FIFO接线；不持业务游标副本 |
| scene | 相机/格坐标转换、场景有序绘制、建筑放置/编辑、实际像素拾取 |
| ui | 按facilities、actors、tasks、village、information、system组织的页面投影、输入和有序计划执行 |
| resources | 素材/SEB解析与绑定、字形需求及运行字体图集；只读assets产品副本 |
| platform | Windows诊断、raylib音频和设备策略 |
| inspection | 有界预运行、截图和绘制采样；不参与正常玩家规则 |

建设21归`ui/facilities/world_build_menu`的view/input/render。完整目录、类别、选择、首行和双钟属于源Owner；桌面仅缓存实际画出的控件、行marker和拖动。一次完整输入交源事务，图纸/住宅H/道路/撤除/移动、空行和详情返回不另造规则。实际EndDrawing后才按Session表现序号提交Draw；同快照重画、纯查询或Draw回执不生成新的呈现机会。父21只有实际绘出才提交，并且覆盖期间没有输入热区。

`world_building`保留74、80、81协调；`world_facility_detail`、`world_facility_upgrade`及商品/强化/口碑模块消费正式有序计划。同一设施可为实例或定义预览，报价、共享成长、邻接和入住资格分别读取；预览与植物不保留隐藏确认区。住宅80仍是已确认的静态子集，完整候选输入等待研究。建设选址、旋转和红绿占地只作预览，付款和占用由worker重验。

人物60四页、职业61–63、赠礼64–66、结果68/69、职业大师70和装备73归actors。任务22–28/31–33的冻结名单、游标、预测及父答案归源Owner；tasks只将其转换为实际字体、有序绘制和设备输入。村办、晋级、奖励、商会、魔法壶、税收与信息页各自保留独立支付、领取、门槛和恢复消费者，不使用通用确认旁路。

`ui/actors/world_monster`统一89正常介绍和92共享定义详情；89早确认只到40，92主钟0可返回。税收90使用真实Init居民、五行与拖条，98自动入账。左上月报自动收起，不确认、不冻结世界；其他模态资格及玩家显式暂停仍生效。绘制不补Init、随机、持久状态或奖励。

标题仍采用产品两栏/草稿/取消保留政策，确认新局或冷载成功后一次安装，再启动WorldSession。标题与游戏内纪录共用system静态计划和独立系统2数据；纪录装饰名单/独立动画Owner、原91动态Owner、平台语言和共享手形宿主未闭合，静态子集不冒充原程序动态。产品不接Steam服务。

`ui/common/steam_plan_draw`统一短寿命GPU/字体末端，页面模块保留各自布局和输入。源资源身份、裁剪、图层、阴影及字体测宽不得按文件名或字符数猜测；Steam差异PNG明确绑定，不能静默回退同名APK图。字队列与即时文字按计划层次执行，输入只用同次实际绘出的几何。

鼠标短点在释放时选择，拖动捕获后不再触发地图点击；右键按当前页返回/主场景菜单处理。generation、页/相位/目录、尺寸变化与失焦清理旧手势，pending拒重复。`SpritePickMap`按实际绘制顺序、图块、翻转与透明像素选择设施或怪物，角色/前景实体能遮挡；地图格只用于放置与编辑。只在点击时读GPU，FIFO再次核稳定实例/定义身份。

`world_audio`主线程持有设备、4条BGM流和22音效，消费Session独立一次性输出FIFO；失败候选和系统写入待重试时不提前播放。PC暂停/失焦不停声、jingle后的恢复门槛是显式设备适配，未认证为Steam生命周期等价；设备缺失明确报告并继续游戏。音量设置和跨局偏好等待维护合同。

窗口诊断的源轮预运行不等待墙钟，但保留实际原消费者与正常单倍速。截图、程序内输入与真实OS鼠标验收分别记录；调试/headless不发布玩家制品，Release包只附必要DLL、资源和字体。
