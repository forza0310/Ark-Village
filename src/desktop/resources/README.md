# 桌面资源

`sprites.cpp` 管理纹理、SEB/PNG 绑定、裁剪与拾取记录；`text.cpp` 管理字体图集、自定义姓名字形、测宽和延后绘字；`asset_check.cpp` 执行无窗口资源解码与边界检查。共同的索引解析和裁片校验位于私有 `resource_metadata`，接口集中在 `resources.hpp`。

纹理和字体由主线程 RAII 持有。地图缩放、逻辑画布和物理像素密度分别处理，UI 标签按既有绘制顺序 flush；加载或扩充字体失败不能留下半个新图集。这里不持有世界状态或结算经营效果。

`effect`与`common`/`common2`使用独立原图索引；当前只消费赠礼闪光dropItem00和回复eff02，首次绘制按原img.inf加载并缓存索引。正文图、人物肖像与特效按正式计划原序绘制，肖像的局部图像裁剪只作用于该图元。未消费的原索引不是全帧认证；来源及使用帧由原skin套件、--check及实际窗口共同核验。
