# ui

二维页面表现与输入适配，依据research/ui/PAGES.md及S001/S002/S003/S005；不复制反编译实现。

- layout：窗口尺寸到逻辑矩形，绘制/命中共用；菜单28行距，目录四行。
- state/controller：临时页面/选中/滚动/预览与返回；只通过Game命令提交业务变化。
- skin：原PNG分段/平铺、SEB手形/数字、内容框角与文字度量。
- hud：日期/金币/村子点数、人气仪表和上下栏。
- pages：主菜单、建设目录、有限设施/人物详情及首访教程；增长后按实际页面再拆文件。

依赖desktop资源/投影与app只读状态，不依赖research运行目录。原版截图是视觉参考，不是纹理。
横屏默认960×512、最小逻辑240×256、再次点同格/Enter建造属于桌面适配，不能称为原版触摸验收。
三个未实现主菜单入口及保存/道具禁用。信息暂直接接已有到访属性页，未复刻信息子菜单/四页定义名单。
设施详情先接普通窗体构图；经营字段未进入模型的显示为---，设备/住宅/植物专用模板和分页仍需接入。
字体由系统TTF替代Android Paint，文字在最终窗口像素绘制；地图/皮肤仍用point采样。
