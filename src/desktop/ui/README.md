# ui

二维页面表现与输入适配，依据research/ui/PAGES.md及S001/S002/S003/S005；不复制反编译实现。

- script_text：解码已证br/颜色/居中标记，未知标签及占位符保留；按真实字体度量/UTF-8边界折行，短框先翻屏再翻段，不截断正文。
- world_tasks：33ee056任务22/23/24/25/27/28/33只读视图、共享布局、输入意图与绘制分开；任务实例/人物定义保留源序，征集名单/费用/预测/期限仅读唯一Owner。键盘/滚动与响应面板是桌面适配，不以身体截图冒充头像。page24仅发送按住边沿，28/33动画由源计数推进；59满70确认、83仅取消、97自动、99/100读真实怪物。
- world_crew_summary：页31只读已初始化crew_summaries与真实击倒/倒地统计，按定义身份解名称，保留名单重复/顺序；五行、共享滚动/确认布局，不重复初始化或发奖。
- world_award：读取raw87真实贡献排序/勋章，结束授勋→实际是/否请求经WorldSession提交；不重算排名、不隐式普通确认或制造raw88授予。原规格未给完整像素布局，表格为桌面适配。raw16/56/57只显示场景并自动推进，raw89沿源40计数快进/关闭，不合并两次确认。
- world_panels：持续世界的页0秘书通知白框与报纸徽标模板、共享确认区域及人气图集裁剪。人气显示实际数值，填充/针位置映射待研究，不造百分比。
- layout：窗口尺寸到逻辑矩形，绘制/命中共用；菜单28行距，目录四行。
- state/controller：临时页面/选中/滚动/预览与返回；只通过Game命令提交业务变化。
- skin：原PNG分段/平铺、SEB手形/数字、内容框角与文字度量。
- hud：日期/金币/村子点数、人气仪表和上下栏；正常场景附桌面暂停/继续按钮，绘制和点击共用layout。
- pages：主菜单、建设目录、有限人物详情及首访教程。
- facility_context/page：页74条件模板与详情绘制。普通实例两页显示经营属性/共享等级/使用阈值、维护费/最多五条邻接来源；定义预览不加实例邻接。

依赖desktop资源/投影与app只读状态，不依赖research运行目录。原版截图是视觉参考，不是纹理。
横屏默认1080×720、最小逻辑240×256、再次点同格/Enter建造属于桌面适配，不能称为原版触摸验收。
三个未实现主菜单入口及保存/道具禁用。信息暂直接接已有到访属性页，未复刻信息子菜单/四页定义名单。
设备/募集/住宅/周边增益分别使用条件模板，未知商品/候选/住户显示---，商品/道具/入住命令禁用。
详情翻页/来源滚动不改业务状态；目录/详情中的滚轮用于列表，场景滚轮调整地图缩放。
字体由系统TTF替代Android Paint，文字在最终窗口像素绘制；地图/皮肤仍用point采样。

暂停按钮与Space共用controller::toggle_pause，仅普通村庄画面可切换；模态页隐藏按钮且不改变显式暂停状态。
该按钮为桌面适配，不是研究截图中的原版控件；暂停时到访、施工、日历不推进。
