# 世界页面表现

按设施 `facilities/`、人物 `actors/`、任务 `tasks/`、村庄经营 `village/`、启动/菜单 `system/` 和公共窗框/HUD `common/` 分组。每个模块只投影不可变Owner、安排布局、生成输入意图和绘制；初始化、支付、奖励、页栈及确认门槛均由模拟线程的源消费者提交。

- 设施：建设目录、详情、商品、强化、入住、升级和地图编辑。目录/预览共用实际定义及完整SEB分片；预览合法不预约资金或占地。81由正式inspect绑定升级矩阵、实例和两份独立页计数，绘制不复位frame2；保留已批准的15像素属性行距。74沿224×172面板及五行适配。
- 人物：60四页、转职、赠礼、成长、大师、装备与税款。`actors/world_human_skin`只读准备并执行正式四页计划，含原序窗框、职业/经验、奖章/装备、HP_NOW/HP_AFTER危险/恢复提示、住宅肖像及四页比例条；`world_human_detail`仅负责面板/PC导航。气泡传实际字体测宽，不用绘制FPS推进人物或页计数。顶部页签和底部捷径保留PC适配；Enter在概览赠礼、属性转职、装备打开所选槽，魔法无确认操作。装备方向先走四槽再翻页，点击只选择；指令/选择和回放字段均由Owner维护。
- 任务：目录、征集/队伍、绑定成员、成果及探索；实例/参与者保持原序，按住输入只发边沿，绘制不代发经验或物品。
- 经营：村办、商会、魔法壶、授勋和逐星页面；目录支付与后继事件交源消费者，效果排队不等于兑现。通知/月报只读源队列和摘要，不由绘制更新寿命、收费或奖励。
- 系统：真实3/4/7/9/10菜单、信息目录、说明13与raw14两栏玩家保存桥；未交付入口保持禁用。说明翻页读取Init冻结载荷，不重抽人物；玩家档与维护全量回放格式分开。

`actors/world_human_skin`也执行装备信息73与装备类赠礼确认65：170×125/220×136源小窗居中，真实测宽、定义参数、原数字升降颜色与目录箭头保持。绘制只给主线程留下上次画出的橙条/箭头几何及语义标签；page、人物、候选、选择、尺寸或generation变化拒绝旧鼠标范围，键盘独立可用，pending拒绝重复。65不付款或装配，答案返回父64后由源消费者提交；普通道具slot4沿既有合同。

`common/skin`复用PNG拼片、SEB图元、逻辑裁剪与文字度量；字体来自随包OTF，PNG使用point采样。默认1080×720、最小逻辑240×256，长文字按已确认页面适配完整测宽，不把截图当贴图或跨版本数值来源。[研究UI示例对照](../../../docs/reference/REFERENCE_CHECKLIST.md#ui-small-window-goal)包括HTTP预览页和正式研究窗口PNG，运行只消费各自正式计划及assets素材。

`../input/world_management`协调UI意图、generation和pending回执；关闭子页不会同击激活父页。目录滚轮用于列表，场景滚轮用于缩放，世界鼠标操作与窗口截图分别验收。旧Game/UI入口已退役，不持第二套世界；运行不读research。

接线和输入验证复用现有world_ui套件，底层规则/回滚/随机由冻结研究套件负责。窗口夹具明确标为合成显示输入，不认证自然解锁或OS鼠标。当前接入与尚缺的完整演出见[B1](../../../docs/stages/B1-playable-prototype.md)及[表现合同缺口](../../../docs/reference/RESEARCH_REQUESTS.md#steam-ui-delegates-1f19c88)。
