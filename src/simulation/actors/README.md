# 人物

人物生命周期、HP/成长、普通移动与路线、设施进出、职业/赠礼和主角焦点控制集中在此；行为选择属于相邻 `ai` 模块，战斗结算属于 `combat`。

人物定义、共享职业进度与实时实例保持各自身份。最大 HP 增长不等于当前 HP 恢复；焦点人物临时进入既有消费者后必须完整提取并移除临时名册项。公开头与本目录对应。

路线、日常和生命周期可消费本轮私有候选，旧人物/地图/路线及邻近观察在转移前保存；回调后的拒绝仍发生在原时点。最终状态与路径审计分别完整保留，不能为减少复制移空返回审计。运行时输入按实际分支准备目录，未消费的装备/经济事实仍执行原验证；公开完整输入入口用于独立对照。

`startup_world_route_facts_private` 只在同步输入准备期间借用当前 Owner 的地表、住宅、邻接、人物资料及定义改良数组。每个原调用点重建任务、朝向和可见性事实；返回的出发/路径/救援/声音输入拥有所需观察，不携带 Owner 或临时 view 的引用，也不跨事件缓存。

人物控制的私有领域段复用已经独立的 routes，命令前项和出发前事件116观察保存为值。攻击14–17的回调可能在叶层仍读源 AI 时替换世界，继续保留独立值路径；公开 const 控制入口也保留该路径作对照。私有拒绝直接丢弃完整候选，不重试或发布半段状态。
