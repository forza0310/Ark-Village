# 产品测试支撑

`world_fixture.hpp` 提供真实新局夹具与完整世界时钟比较，供产品自有测试复用；冻结的 `tests/simulation` 保留研究来源，不依赖这里。

- `initial_world(seed)` 调用真实新局初始化，返回独立可变副本。常用 seed1 在每个测试进程内缓存不可变初态，其余种子独立初始化；不自动确认、不推进时间、不补人物或资金。测试内的业务夹具由调用点显式修改。
- `same_world_clock` 比较六个日期字段以及世界更新、模拟步数、到访计数，只表达时钟未变；现金、随机、页面、人物等仍由各套件检查，不表示完整 Owner 相等。

显示边界测试的小型合成夹具保留在各自套件，避免为局部绘制检查启动完整世界。共用支撑不减少场景、循环、种子或数值边界覆盖。


`checks.hpp`只提供Release有效的断言、计数和case诊断，不准备业务数据；`case_runner.hpp`只按命令行选择一个case并传播失败，不隐式全跑。两组共享可执行的每个CTest仍启动独立进程，case内创建自己的`Checks`。它们与`world_fixture.hpp`的数据准备职责分开；不引入外部测试框架。
